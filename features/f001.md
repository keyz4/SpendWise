# f001 — MongoDB Database Connection

| Field          | Value                              |
|----------------|------------------------------------|
| **Feature Code** | f001                             |
| **Title**        | MongoDB Database Connection      |
| **Priority**     | 🔴 Critical (Blocker)            |
| **Difficulty**   | 🟢 Easy                          |
| **Depends On**   | None                             |
| **Estimated Time** | 1–2 hours                      |

---

## 1. Overview

This feature establishes the foundational database connection between the SpendWise Express server and a MongoDB instance. Without this, no other backend feature can function. This is the very first thing a developer must implement.

---

## 2. End Goal

When this feature is complete:

- The server connects to MongoDB on startup using Mongoose.
- The connection string is read from a `.env` file (`MONGODB_URI`).
- The server logs a success or failure message to the console.
- If the connection fails, the server exits gracefully with a non-zero exit code.
- The connection is established **before** the Express server begins listening for requests.

---

## 3. Product Requirements (PRD)

### 3.1 Functional Requirements

| ID     | Requirement                                                                 |
|--------|-----------------------------------------------------------------------------|
| FR-001 | The server MUST read `MONGODB_URI` from environment variables.              |
| FR-002 | The server MUST connect to MongoDB using Mongoose before accepting requests. |
| FR-003 | The server MUST log `"✅ MongoDB connected successfully"` on a successful connection. |
| FR-004 | The server MUST log a descriptive error message and exit with code `1` on failure. |
| FR-005 | The connection function MUST be importable and callable from `server/src/index.ts`. |
| FR-006 | If `MONGODB_URI` is not set, the server MUST fall back to `mongodb://localhost:27017/spendwise`. |

### 3.2 Non-Functional Requirements

| ID      | Requirement                                                                |
|---------|----------------------------------------------------------------------------|
| NFR-001 | Connection timeout should be 10 seconds (Mongoose default is fine).        |
| NFR-002 | The implementation should not block the event loop.                        |

## 5. Detailed Implementation Steps

### Step 1 — Create `.env` from `.env.example`

Copy `server/.env.example` to `server/.env` and set:
```
MONGODB_URI=mongodb://localhost:27017/spendwise
```

### Step 2 — Implement `connectDB()` in `server/src/config/db.ts`

Open the file. You'll see the function body is commented out. Implement it:

1. Call `mongoose.connect(mongoURI)` using the `MONGODB_URI` env var.
2. Log `"✅ MongoDB connected successfully"` on success.
3. In the `catch` block, log the error and call `process.exit(1)`.

### Step 3 — Wire up in `server/src/index.ts`

1. Uncomment the import: `import { connectDB } from "./config/db";`
2. Change the `app.listen` block to:
   ```typescript
   const start = async () => {
     await connectDB();
     app.listen(PORT, () => {
       console.log(`🚀 SpendWise server running on http://localhost:${PORT}`);
     });
   };
   start();
   ```

- [ ] Server starts and prints `"✅ MongoDB connected successfully"` followed by `"🚀 SpendWise server running on http://localhost:5000"`
- [ ] If MongoDB is not running, server prints an error and exits with code 1

## 7. Testing

### Manual Test
1. Start MongoDB locally (`mongod` or Docker).
2. Run `npm run dev:server` from the root.
3. Confirm the success log appears.
4. Stop MongoDB, restart the server, confirm the error log and exit.
