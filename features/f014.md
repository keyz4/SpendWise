## 1. Overview

This is the final polish feature. It wires up the Settings page (profile update, password change, preferences), adds global error handling and toast notifications, implements loading states across the app, adds a mobile-responsive sidebar toggle, and generally improves the user experience.

---

## 2. End Goal

When this feature is complete:

- Users can update their name and email from Settings.
- Users can change their password from Settings.
- A toast notification system shows success/error messages globally.
- API errors are caught and displayed in a user-friendly way (not raw error objects).
- The sidebar is collapsible on mobile (hamburger menu in Topbar).
- All forms have proper validation feedback.
- The app feels polished and production-ready.

## 5. Detailed Implementation Steps

### Step 1 — Toast System

Create a simple context-based toast system:
1. `ToastContext` holds an array of active toasts and an `addToast(type, message)` function.
2. `Toaster` component renders toasts in a fixed-position container (top-right).
3. Each toast has a colored left border (green for success, red for error, etc.) and auto-dismisses.

### Step 2 — Settings API

Create two new backend endpoints:
- `PUT /api/auth/profile` — updates name and email (requires auth).
- `PUT /api/auth/password` — changes password (requires auth + current password verification).

### Step 3 — Settings Page Wiring

Connect the existing form fields to API calls. Use the toast system for feedback.

### Step 4 — Mobile Sidebar

1. Add state in `MainLayout` for sidebar visibility.
2. Pass toggle function to `Topbar` (hamburger button).
3. On mobile, sidebar overlays the content with a semi-transparent backdrop.
4. Clicking a nav link or the backdrop closes the sidebar.
5. Use Tailwind responsive classes and `transition-transform` for animation.

### Step 5 — Not Found Page

Simple page with a "Page not found" message and a "Go Home" button.

### Step 6 — Global Error Handler

In the Axios response interceptor, catch errors and show toasts:
```typescript
api.interceptors.response.use(
  response => response,
  error => {
    const message = error.response?.data?.message || "Something went wrong";
    // Trigger toast (you'll need a way to call toast outside React components,
    // or handle errors in each component individually)
    return Promise.reject(error);
  }
);
```
