## 1. Overview

This feature adds a UI for users to view, create, and delete custom categories. Categories are currently hardcoded in filter dropdowns and transaction/budget modals. This feature replaces those hardcoded lists with data fetched from the API, and adds a management section (either on the Settings page or as a standalone section).

---

## 2. End Goal

When this feature is complete:

- Users can see all their categories (default + custom) organized by type (income / expense).
- Users can create a custom category with a name, type, and color.
- Users can delete custom categories (but NOT default categories).
- All dropdowns across the app (Transactions filters, Transaction modal, Budget modal) are populated from the categories API.
- A reusable hook `useCategories()` fetches and caches categories.

### 3.2 Where to Place the UI

**Recommended:** Add a "Categories" section to the Settings page, under a new heading. This avoids adding a new route but keeps it discoverable.

**Alternative:** Add a `/categories` route to the sidebar. If you choose this, update `Sidebar.tsx` to include the new nav item.

## 5. Detailed Implementation Steps

### Step 1 — Create API Functions (`client/src/api/categories.ts`)

```typescript
import api from "./axios";

export const getCategories = async () => {
  const response = await api.get("/categories");
  return response.data;
};

export const createCategory = async (data: { name: string; type: string; color: string }) => {
  const response = await api.post("/categories", data);
  return response.data;
};

export const deleteCategory = async (id: string) => {
  await api.delete(`/categories/${id}`);
};
```

### Step 2 — Create `useCategories()` Hook

```typescript
export function useCategories() {
  const [categories, setCategories] = useState([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    getCategories().then(setCategories).finally(() => setLoading(false));
  }, []);

  const incomeCategories = categories.filter(c => c.type === "income");
  const expenseCategories = categories.filter(c => c.type === "expense");

}
```

### Step 3 — Add Categories Section to Settings Page

Under the "Preferences" section in Settings, add a "Categories" card that:
1. Lists categories in two columns: Income | Expense.
2. Shows each category with its color dot and name.
3. Custom categories have a trash icon button.
4. An "Add Category" button at the bottom opens a small inline form.

### Step 4 — Update All Dropdowns

Replace hardcoded `<option>` elements in filter dropdowns and modals with options generated from `useCategories()`.
