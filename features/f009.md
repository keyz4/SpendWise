## 1. Overview

This feature brings the Transactions page to life by connecting it to the real backend API, implementing the "Add Transaction" modal with a form, enabling Edit and Delete actions on existing transactions, wiring up the filter controls (type, category, date range), and implementing pagination. This is the most complex frontend feature.

---

## 2. End Goal

When this feature is complete:

- The Transactions page fetches and displays real transactions from the API.
- Users can add a new transaction via a modal form.
- Users can edit an existing transaction (pre-populated modal).
- Users can delete a transaction (with confirmation).
- Filter controls (type, category, date range) actually filter the results by querying the API.
- Pagination controls navigate between pages of results.
- A loading spinner is shown while data is being fetched.
- Empty states are shown when no transactions exist.

## 5. Detailed Implementation Steps

### Step 1 — Implement API Functions (`client/src/api/transactions.ts`)

Replace every `throw new Error("Not implemented yet")` with real Axios calls:
```typescript
export const getTransactions = async (filters?: TransactionFilters) => {
  const response = await api.get("/transactions", { params: filters });
  return response.data;
};
```

### Step 2 — Create `TransactionModal` Component

A modal dialog with:
- **Type**: radio buttons or dropdown (income / expense)
- **Amount**: number input with validation (must be > 0)
- **Category**: dropdown populated from categories API
- **Description**: text input (max 200 chars)
- **Date**: date picker (default: today)
- **Submit** and **Cancel** buttons
- If editing, pre-fill all fields from the transaction prop.

### Step 3 — Create `DeleteConfirm` Component

A simple confirmation modal: "Are you sure you want to delete this transaction? This action cannot be undone."

### Step 4 — Rewrite `Transactions.tsx`

1. Add state: `transactions`, `loading`, `error`, `page`, `totalPages`, `filters`, `isModalOpen`, `editingTransaction`.
2. `useEffect` to fetch on mount and whenever `page` or `filters` change.
3. Wire filter dropdowns to update `filters` state.
4. Wire pagination to update `page` state.
5. Wire Add/Edit/Delete buttons to their respective handlers.
