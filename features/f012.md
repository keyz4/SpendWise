## 1. Overview

The Dashboard page currently has two chart placeholder boxes. This feature replaces them with interactive, real-data charts using the **Recharts** library (already installed). The two charts are:

1. **Spending Trends** — A line or bar chart showing monthly income vs. expenses over the last 6 months.
2. **Spending by Category** — A pie or donut chart showing expense distribution by category for the current month.

---

## 2. End Goal

When this feature is complete:

- The "Spending Trends" placeholder is replaced with an interactive area/bar chart.
- The "Spending by Category" placeholder is replaced with an interactive pie chart.
- Charts display real data fetched from the transaction API.
- Charts are responsive and resize with the container.
- Charts have tooltips and legends.
- The summary cards at the top of the Dashboard show real calculated values.

## 3. Product Requirements (PRD)

### 3.1 Functional Requirements

| ID     | Requirement                                                                       |
|--------|-----------------------------------------------------------------------------------|
| FR-001 | **Spending Trends chart** MUST show 6 months of data (current month + 5 previous). |
| FR-002 | Each month MUST show two bars/lines: total income and total expenses.              |
| FR-003 | X-axis MUST show month labels (e.g., "Oct", "Nov", "Dec", "Jan", "Feb", "Mar").   |
| FR-004 | Y-axis MUST show dollar amounts with proper formatting.                           |
| FR-005 | Hovering over a data point MUST show a tooltip with the exact amount.             |
| FR-006 | **Category chart** MUST show the current month's expenses grouped by category.    |
| FR-007 | Category chart MUST use distinct colors for each category.                        |
| FR-008 | Category chart MUST show category name and amount on hover.                       |
| FR-009 | Summary cards MUST show real values: total balance (income - expenses), total income, total expenses, savings (income - expenses for current month). |
| FR-010 | The "change" percentage on cards MUST compare current month vs. previous month.   |
| FR-011 | Charts MUST show a loading skeleton while data is being fetched.                  |
| FR-012 | Charts MUST show "No data available" if there are no transactions.                |

### 3.2 Data Aggregation

The frontend should fetch all transactions for the last 6 months (or create a backend analytics endpoint) and aggregate:

**Option A — Frontend Aggregation:**
- Fetch transactions with `?startDate=6_months_ago&limit=1000`.
- Group by month for trends, group by category for pie chart.

**Option B — Backend Analytics Endpoint (recommended for performance):**
- Create `GET /api/transactions/analytics/trends` → returns monthly totals.
- Create `GET /api/transactions/analytics/categories` → returns category totals.

Either approach is acceptable. Option A is simpler to implement first.

## 5. Detailed Implementation Steps

### Step 1 — Fetch Transaction Data

In `Dashboard.tsx`, add a `useEffect` that fetches the last 6 months of transactions.

### Step 2 — Aggregate for Trends Chart

```typescript
const monthlyData = transactions.reduce((acc, tx) => {
  const month = new Date(tx.date).toLocaleString("en", { month: "short" });
  if (!acc[month]) acc[month] = { month, income: 0, expenses: 0 };
  if (tx.type === "income") acc[month].income += tx.amount;
  else acc[month].expenses += tx.amount;
  return acc;
}, {});
```

### Step 3 — Build Trends Chart

```tsx
<ResponsiveContainer width="100%" height={256}>
  <BarChart data={Object.values(monthlyData)}>
    <CartesianGrid strokeDasharray="3 3" />
    <XAxis dataKey="month" />
    <YAxis />
    <Tooltip />
    <Legend />
    <Bar dataKey="income" fill="#22c55e" name="Income" />
    <Bar dataKey="expenses" fill="#ef4444" name="Expenses" />
  </BarChart>
</ResponsiveContainer>
```

### Step 4 — Aggregate for Category Chart

```typescript
const categoryData = transactions
  .filter(tx => tx.type === "expense")
  .reduce((acc, tx) => {
    if (!acc[tx.category]) acc[tx.category] = 0;
    acc[tx.category] += tx.amount;
    return acc;
  }, {});
```

### Step 5 — Build Pie Chart

```tsx
const COLORS = ["#6366f1", "#ec4899", "#f59e0b", "#22c55e", "#3b82f6", "#ef4444"];

<ResponsiveContainer width="100%" height={256}>
  <PieChart>
    <Pie data={Object.entries(categoryData).map(([name, value]) => ({ name, value }))}
         cx="50%" cy="50%" innerRadius={60} outerRadius={100}
         dataKey="value" label>
      {Object.keys(categoryData).map((_, i) => (
        <Cell key={i} fill={COLORS[i % COLORS.length]} />
      ))}
    </Pie>
    <Tooltip />
    <Legend />
  </PieChart>
</ResponsiveContainer>
```

### Step 6 — Update Summary Cards

Replace hardcoded `summaryCards` array with computed values from transaction data.
