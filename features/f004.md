## 1. Overview

Categories are used to classify transactions (e.g., "Food", "Transport", "Entertainment"). This feature implements the backend API for creating, reading, and deleting categories. There are two types of categories: **default** (system-provided, `userId: null`) and **custom** (user-created, `userId: <userId>`).

---

## 2. End Goal

When this feature is complete:

- `GET /api/categories` returns all default categories + categories created by the authenticated user.
- `POST /api/categories` allows a user to create a custom category with a name, type, color, and icon.
- `DELETE /api/categories/:id` deletes a custom category (default categories cannot be deleted).
- A seed script populates the database with default categories on first run.
- Duplicate category names per user are rejected.

## 5. Detailed Implementation Steps

### Step 1 — Add Compound Index (`server/src/models/Category.ts`)

Uncomment the compound index to enforce unique category names per user:
```typescript
CategorySchema.index({ name: 1, userId: 1 }, { unique: true });
```

### Step 2 — Create Seed Script (`server/src/config/seed.ts`)

Create a function `seedCategories()` that:
1. Checks if any categories with `userId: null` exist.
2. If none, inserts the default categories from the table above.
3. Logs how many categories were seeded.

### Step 3 — Implement Controller Handlers

**getCategories:**
1. Get `userId` from `req.user.id`.
2. Query `Category.find({ $or: [{ userId: null }, { userId }] })`.
3. Return the array.

**createCategory:**
1. Extract `name`, `type`, `color`, `icon` from `req.body`.
2. Set `userId` to `req.user.id`.
3. Try to create. If duplicate key error, return `400`.
4. Return `201` with the new category.

**deleteCategory:**
1. Find category by ID.
2. If `userId` is `null`, return `403` ("Cannot delete default category").
3. If `userId` doesn't match `req.user.id`, return `403`.
4. Delete and return `200`.
