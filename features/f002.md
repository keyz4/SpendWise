## 1. Overview

This feature implements the core authentication API — allowing users to register a new account and log in with their credentials. It involves password hashing with `bcryptjs`, JWT token generation with `jsonwebtoken`, and proper input validation. No frontend changes are required; this is backend-only.

---

## 2. End Goal

When this feature is complete:

- A user can register via `POST /api/auth/register` with name, email, and password.
- A user can log in via `POST /api/auth/login` with email and password.
- Passwords are **never** stored in plain text — they are hashed with bcryptjs.
- On successful register/login, the server returns a **JWT token** and user data.
- Duplicate email registration is rejected with a clear error.
- `GET /api/auth/me` returns the currently authenticated user's profile (requires token).

## 5. Detailed Implementation Steps

### Step 1 — User Model Enhancements (`server/src/models/User.ts`)

1. **Pre-save hook** — Hash the password before saving:
   ```typescript
   import bcrypt from "bcryptjs";

   UserSchema.pre("save", async function (next) {
     if (!this.isModified("password")) return next();
     const salt = await bcrypt.genSalt(10);
     this.password = await bcrypt.hash(this.password as string, salt);
     next();
   });
   ```

2. **Compare password method**:
   ```typescript
   UserSchema.methods.comparePassword = async function (candidatePassword: string): Promise<boolean> {
     return bcrypt.compare(candidatePassword, this.password);
   };
   ```

3. **Generate JWT method**:
   ```typescript
   import jwt from "jsonwebtoken";

   UserSchema.methods.generateToken = function (): string {
     return jwt.sign({ id: this._id }, process.env.JWT_SECRET!, {
       expiresIn: process.env.JWT_EXPIRE || "30d",
     });
   };
   ```

4. Update the `IUser` interface to include these methods.

### Step 2 — Auth Controller (`server/src/controllers/authController.ts`)

Implement the three handlers. Each has commented TODOs with step-by-step instructions already in the code.

**Register:**
1. Extract `name`, `email`, `password` from `req.body`.
2. Check if a user with that email already exists (`User.findOne({ email })`).
3. If exists, return `400`.
4. Create the user (`User.create({ name, email, password })`). The pre-save hook hashes the password automatically.
5. Generate a JWT using `user.generateToken()`.
6. Return `201` with `{ token, user: { id, name, email } }`.

**Login:**
1. Extract `email`, `password` from `req.body`.
2. Find user by email with `User.findOne({ email }).select("+password")` (password is excluded by default).
3. If user not found, return `401` with `"Invalid credentials"`.
4. Compare password using `user.comparePassword(password)`.
5. If mismatch, return `401`.
6. Generate JWT and return `200` with `{ token, user }`.

**GetMe:**
1. Get user ID from `req.user.id` (set by auth middleware — implemented in f003).
2. Find user by ID (without password).
3. Return `200` with user data.

### Step 3 — Wire Up Auth Route

In `server/src/routes/auth.ts`, uncomment the import of `protect` and the protected `/me` route.
