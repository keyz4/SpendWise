## 1. Overview

The Insights page provides deeper analytical views into the user's financial data. While the Dashboard shows a high-level overview, Insights provides trends, comparisons, and breakdowns that help users understand their spending patterns and make better financial decisions.

This page has four chart areas currently showing placeholders. Each must be implemented with a specific visualization.

---

## 2. End Goal

When this feature is complete:

- **Monthly Trends** — An area chart comparing income vs. expenses over the last 12 months.
- **Category Breakdown** — A horizontal bar chart or treemap showing the top expense categories.
- **Savings Rate** — A line chart showing the savings percentage (income−expenses)/income over time.
- **Top Expenses** — A ranked list or bar chart of the top 10 individual expenses in the current month.
- All charts are interactive with tooltips and responsive sizing.
- Date range selector allows users to view different time periods.

---

## 3. Product Requirements (PRD)

### 3.1 Functional Requirements

| ID     | Requirement                                                                      |
|--------|----------------------------------------------------------------------------------|
| FR-001 | **Monthly Trends** — Area chart with two filled areas (income in green, expenses in red) over 12 months. |
| FR-002 | **Category Breakdown** — Horizontal bar chart ranking categories by total spend (top 8). |
| FR-003 | **Savings Rate** — Line chart showing percentage saved per month. Formula: `((income - expenses) / income) * 100`. Months with 0 income show 0%. |
| FR-004 | **Top Expenses** — Sorted list or bar chart of the 10 largest individual expense transactions in the selected period. |
| FR-005 | A date range selector at the top MUST allow switching between: "Last 3 months", "Last 6 months", "Last 12 months", "This year", "Custom". |
| FR-006 | Changing the date range MUST re-fetch and re-render all charts.                  |
| FR-007 | Each chart MUST have a loading skeleton while fetching.                          |
| FR-008 | Hovering over any chart element MUST show a formatted tooltip.                   |

### 3.2 Backend Support (Optional Enhancement)

To avoid fetching thousands of transactions and aggregating on the client, consider creating:

- `GET /api/transactions/analytics/monthly-summary` — returns `{ month, income, expenses }[]`
- `GET /api/transactions/analytics/category-summary` — returns `{ category, total }[]`
- `GET /api/transactions/analytics/top-expenses?limit=10` — returns top-N transactions

These are **optional** — you can start with client-side aggregation and optimize later.

## 5. Detailed Implementation Steps

### Step 1 — Data Fetching

Fetch transactions for the selected date range. If handling client-side:
```typescript
const startDate = subMonths(new Date(), selectedMonths);
const transactions = await getTransactions({ startDate, limit: 5000 });
```

### Step 2 — Monthly Trends (AreaChart)

```tsx
<ResponsiveContainer width="100%" height={256}>
  <AreaChart data={monthlyData}>
    <CartesianGrid strokeDasharray="3 3" />
    <XAxis dataKey="month" />
    <YAxis />
    <Tooltip />
    <Legend />
    <Area type="monotone" dataKey="income" stroke="#22c55e" fill="#22c55e" fillOpacity={0.3} />
    <Area type="monotone" dataKey="expenses" stroke="#ef4444" fill="#ef4444" fillOpacity={0.3} />
  </AreaChart>
</ResponsiveContainer>
```

### Step 3 — Category Breakdown (Horizontal BarChart)

```tsx
<BarChart data={categoryData} layout="vertical">
  <XAxis type="number" />
  <YAxis type="category" dataKey="category" width={100} />
  <Tooltip />
  <Bar dataKey="total" fill="#6366f1" />
</BarChart>
```

### Step 4 — Savings Rate (LineChart)

Compute savings rate per month, then render with `<LineChart>`.

### Step 5 — Top Expenses (List or BarChart)

Sort transactions by amount descending, take top 10, display as a styled list or horizontal bar chart.

### Step 6 — Date Range Selector

Add a select dropdown or button group at the top of the page. On change, re-fetch data with the new date range.
